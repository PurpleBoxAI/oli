# Shared templates

Used by every edition. Copy, fill the [brackets], keep the originals unchanged.

- `rules-template.md`: the business facts and the hard rules. Becomes the "Local Growth Pack rules" file in the owner's Claude Project, or the ChatGPT Project instructions.
- `intake-call-script-template.md`: the call answering script. Owner approves; franchisor approves brand wording.
- `lead-log-template.csv`: the Lead Log header row. Import into a new Google Sheet in the owner's Drive. Column definitions: `10-methodology/04-data-model.md`.

Placeholder names used across all templates: [business name], [owner name], [brand], [territory], [service type], [service options], [service ZIPs], [callback promise], [sheet name], [careers link], [phone], [address], [location page URL], [owner mobile], [customer name], [first name].
