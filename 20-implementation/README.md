# Level 2: Implementation guides

Level 1 (`10-methodology/`) says what to do. This folder says how to do it on a specific AI stack, in the owner's own accounts.

- `claude/`: the Claude edition. A plugin with five skills, plus a setup guide.
- `chatgpt/`: the ChatGPT edition. Project instructions and scheduled task prompts, plus a setup guide.
- `shared/`: templates every edition uses: the rules file, the intake call script, the Lead Log.

Each guide follows the same outline so you can compare: mapping from the five workflows to the stack's mechanisms; prerequisites and plan gating with sources and dates; setup steps; verification checklist; known limits and workarounds; operations; hand-over and management notes.

Product features and plan limits change. Every claim below carries a source and an as-of date; re-check the source before you rely on it.
