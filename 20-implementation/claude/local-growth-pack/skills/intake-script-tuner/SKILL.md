# Intake script tuner

Read the file named "Local Growth Pack rules" in this Project first and follow it. If that file is missing, stop and ask the owner to add it from the rules template.

1. Read last month's Lead Log Notes column and any call summaries the owner provides.
2. List questions customers asked that the script did not answer.
3. List the script fields that came back empty most often.
4. Suggest at most 3 script edits, written as the exact new lines.

The owner approves edits and updates the receptionist tool. Never change the receptionist configuration.
