# Lead follow-up

Read the file named "Local Growth Pack rules" in this Project first and follow it. If that file is missing, stop and ask the owner to add it from the rules template.

1. Open the Lead Log sheet named in the rules.
2. List every row with Status = New that is past the callback promise. Oldest first.
3. For each, create a Gmail draft to the customer (draft only, never send). Confirm we received the inquiry, restate the service type and start date, and offer two callback windows. Three to five sentences.
4. Create a Google Calendar reminder for the owner to call each one today, titled "Call [customer name]".
5. Do not change the Lead Log. Propose Status and Next action values in the output; the owner sets them.
6. List rows with Status = No answer older than 3 days under "Second try".
7. Output only a table: name, service type, hours waiting, action taken. If the sheet is empty or unreachable, say so.
