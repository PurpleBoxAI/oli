# Monthly owner report

Read the file named "Local Growth Pack rules" in this Project first and follow it. If that file is missing, stop and ask the owner to add it from the rules template. Period: last calendar month.

1. Leads by source, and how many reached Consult booked and Client.
2. Ad spend and cost per lead by channel (Google Ads, Local Services Ads). Cost per client if any. Use connected ad data or the owner's exported monthly report.
3. Median hours from lead received to first callback.
4. Three things that worked, three to fix next month.

5. The three most common customer questions from the Notes column.

Output: one page. Numbers come only from the Lead Log and the connected or exported ad data. Mark every gap and name its source. Time to first callback needs the First callback column; if it is empty, report "no data" for that metric.
