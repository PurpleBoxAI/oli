# Weekly ads review

Read the file named "Local Growth Pack rules" in this Project first and follow it. If that file is missing, stop and ask the owner to add it from the rules template.

Use the Google Ads data the owner has connected, read-only. If no ad data connection exists, ask the owner for the exported weekly campaign and search-terms reports and read those files. Change nothing.

Compare the last 7 days with the 7 days before.
1. Per campaign: spend, clicks, calls, conversions, cost per lead.
2. Search terms that cost money and do not match a real customer (for example job seekers). List them as negative keyword candidates.
3. Any targeting outside the service ZIP codes in the rules.
4. Cross-check ad conversions against Lead Log rows with Source = Google Ads.
5. If the owner has connected Google Analytics, add sessions and conversions for the location page for the same two periods. Otherwise skip this step and say so.

Output: at most 3 recommended changes, each with the reason and the exact click path in Google Ads. Use only numbers the data returns. Mark missing data and name the connection or file that did not provide it.
