# Reviews and profile

Read the file named "Local Growth Pack rules" in this Project first and follow it. If that file is missing, stop and ask the owner to add it from the rules template.

1. For each new review (pasted by the owner, or from a profile connector if one is approved): draft a reply that thanks the reviewer by first name, mentions one specific detail from the review, shares no private details, and runs two to three sentences.
2. For a negative review: draft a calm reply that offers a phone call, and flag it to the owner at the top of the output.
3. Draft one Google Business Profile post for this week, 60 to 120 words, about one service from the rules, ending with a call to action to call the office.

Output: drafts only, each labeled for copy and paste.
